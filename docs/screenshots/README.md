## Shot list (recommended)

| File           | What to capture                                                            |
| -------------- | -------------------------------------------------------------------------- |
| `overlay.png`  | The overlay on top of **Palworld** (borderless-windowed) — the money shot. |
| `planner.png`  | **Planner** tab with a base's worker lineup filled in.                     |
| `bases.png`    | **Bases** tab showing a base template + progression roadmap.               |
| `breeding.png` | **Breeding** tab: a parent-A + parent-B result, or the path finder.        |
| `mounts.png`   | (optional) **Mounts** tab ranked by speed.                                 |

## Tips

- Capture at a clean, consistent size; PNG.
- The `overlay.png` over the game sells the "always-on-top companion" value instantly — lead with it.
- Keep file sizes reasonable (these ship in the repo and the Nexus page).
